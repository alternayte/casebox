description: "A rule of Casebox refused what the request asked for."
---

## What happened

A rule of Casebox refused what the request asked for. The message says which rule.

## What to do

Read the message and change the request: it names the value or the step that is missing. If the message does not tell you what to change, report it as a bug, with the message.

This page says what CBX002 means and how you fix it.

## What happened

The request names something that does not exist in your organisation: a workspace, a case, an evaluation, a pattern or a proposal. Another organisation's objects are never visible.

## What to do

Check the ID or name in the command or URL. `casebox doctor` shows which server and organisation this machine uses.

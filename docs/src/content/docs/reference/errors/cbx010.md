This page says what CBX010 means and how you fix it.

## What happened

The request has no valid login or token: the CLI login expired, the token was revoked, or the token belongs to another server.

## What to do

Run `casebox init` or `casebox join` to log in again. For a worker or CI token, issue a new one with `casebox token create` and update `CASEBOX_WORKER_TOKEN` or `CASEBOX_TOKEN`.

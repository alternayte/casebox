title: "CBX011: Not allowed"
description: "Your account's role, or the token's kind, does not allow this route."
---

This page says what CBX011 means and how you fix it.

## What happened

Your account's role, or the token's kind, does not allow this route. Viewers read; Members run evaluations and review cases; Admins change settings, integrations and tokens. A worker token only leases jobs, and a ci token only acts on its own CI runs.

## What to do

Ask an Owner or Admin for the role you need, or use a token of the right kind.

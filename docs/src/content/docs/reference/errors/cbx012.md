---
title: "CBX012: The server cannot be reached"
description: "The CLI could not open a connection to the Casebox server."
---

This page says what CBX012 means and how you fix it.

## What happened

The CLI could not open a connection to the Casebox server.

## What to do

Check the server URL (`server` in `.casebox/casebox.yml`, `CASEBOX_SERVER`, or the `--server` flag) and that the server runs: `casebox up` for a local trial, or your team's deployment. From a CI runner, the server must be reachable from the runner's network.

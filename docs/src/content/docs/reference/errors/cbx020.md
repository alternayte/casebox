title: "CBX020: The repository is not enrolled"
description: "The command needs `.casebox/casebox.yml` in the repository, and this repository has none."
---

This page says what CBX020 means and how you fix it.

## What happened

The command needs `.casebox/casebox.yml` in the repository, and this repository has none.

## What to do

Run `casebox init` in the repository (an Admin), or `casebox join` if a teammate already committed the file.

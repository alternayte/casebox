---
title: "CBX022: casebox.yml names no workspace"
description: "The command works on a workspace, and casebox.yml has no `workspace` key."
---

This page says what CBX022 means and how you fix it.

## What happened

The command works on a workspace, and casebox.yml has no `workspace` key. A shared harness repository has none by design, so workspace commands do not run there.

## What to do

Add `workspace: <name>` to casebox.yml, or run `casebox init`.

---
title: "CBX040: The workspace does not exist"
description: "The workspace named in casebox.yml or the request does not exist on this server."
---

This page says what CBX040 means and how you fix it.

## What happened

The workspace named in casebox.yml or the request does not exist on this server.

## What to do

Run `casebox init` in the repository to create it, or correct `workspace` in casebox.yml.

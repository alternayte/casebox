---
title: "CBX041: The repository's code host is unknown"
description: "The repository name is not a GitHub repository and starts with no Azure DevOps collection Casebox knows."
---

This page says what CBX041 means and how you fix it.

## What happened

The repository name is not a GitHub repository (`host/owner/name`), and it starts with no Azure DevOps collection URL that Casebox knows. Casebox needs the collection to read the repository.

## What to do

Run `casebox init` in the repository. It asks for the collection URL, such as `https://ado.example.com/tfs/DefaultCollection`. To add the repository through the API, send the collection with it:

```bash
casebox api POST /api/v1/workspaces/<workspace>/repos --data '{"repo":"<name>","collection":"<collection URL>"}'
```

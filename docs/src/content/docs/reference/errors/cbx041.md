This page says what CBX041 means and how you fix it.

## What happened

Cases are mined and validated only in a workspace whose environment recipe a person confirmed, because automated setup often fails.

## What to do

Run `casebox env check` to build the recipe and run the tests, then `casebox env confirm`.

## What happened

Harness CI compares a pull request with the cached score of the default branch's harness. No approved dev case has a score for this agent and model yet.

## What to do

Run the baseline: `casebox ci --baseline` on the default branch, or wait for the scheduled nightly run. Then push the pull request again.

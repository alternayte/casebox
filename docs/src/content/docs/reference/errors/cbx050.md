## What happened

The worker needs a sandbox provider to prepare environments, validate cases and run agents, and none answers.

## What to do

For Docker, start Docker and check `docker info`. For Kiln or Daytona, set `CASEBOX_SANDBOX` and the provider's credentials. `casebox doctor` shows what the worker finds.

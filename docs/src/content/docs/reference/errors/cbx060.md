---
title: "CBX060: No model key on the worker"
description: "The worker runs agents with the model keys in its own environment; the server never holds them."
---

## What happened

The worker runs agents with the model keys in its own environment; the server never holds them. This worker has none.

## What to do

Set `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` or `CURSOR_API_KEY` in the worker's environment, or in the Action's `env`.

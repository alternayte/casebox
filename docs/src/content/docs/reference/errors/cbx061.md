## What happened

Steering classification, case instructions, pattern clustering and proposals need an analysis model, and this worker has none configured.

## What to do

Set `CASEBOX_ANALYSIS_PROVIDER` (`anthropic` or `openai`) and `CASEBOX_ANALYSIS_MODEL`, and optionally `CASEBOX_ANALYSIS_BASE_URL` and `CASEBOX_ANALYSIS_API_KEY`.

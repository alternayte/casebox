---
title: "CBX062: Unknown agent version"
description: "Agent flags are pinned per agent version, and this version is not in Casebox's table."
---

This page says what CBX062 means and how you fix it.

## What happened

Agent flags are pinned per agent version, and this version is not in Casebox's table.

## What to do

Use a version the message lists in `agent_version` of casebox.yml, or upgrade Casebox for newer agent versions.

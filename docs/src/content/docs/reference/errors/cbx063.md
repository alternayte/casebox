This page says what CBX063 means and how you fix it.

## What happened

A shared harness goes into the agent's user-level configuration. Only Claude Code and Codex have one that Casebox knows.

## What to do

Use claude-code or codex as the evaluation's agent, or move the shared harness files into the repositories.

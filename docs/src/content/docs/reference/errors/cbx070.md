This page says what CBX070 means and how you fix it.

## What happened

Harness CI comments and proposal pull requests go through the organisation's GitHub connection, and there is none.

## What to do

Connect GitHub with `casebox init` (a token) or as a GitHub App. The credential needs pull requests write, and contents write for proposals.

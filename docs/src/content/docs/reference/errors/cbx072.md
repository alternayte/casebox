---
title: "CBX072: Jira refused the token"
description: "Jira Data Center did not accept the personal access token."
---

This page says what CBX072 means and how you fix it.

## What happened

Jira Data Center did not accept the personal access token.

## What to do

Create a new personal access token in Jira (Profile, Personal Access Tokens) and connect it again with `casebox init`.

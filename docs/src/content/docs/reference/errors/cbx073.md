---
title: "CBX073: Azure DevOps refused the token"
description: "The Azure DevOps Server collection did not accept the personal access token, or it could not be reached."
---

This page says what CBX073 means and how you fix it.

## What happened

The Azure DevOps Server collection did not accept the personal access token, or the server could not reach the collection URL.

## What to do

1. Open the collection URL in a browser from the machine that runs the Casebox server. It must answer.
2. Create a personal access token in that collection with the scopes Code (Read) and Identity (Read).
3. Run `casebox init` again in the repository, and give it the new token.

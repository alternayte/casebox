---
title: "CBX090: No prompt mode chosen"
description: "Capture stays off until an Admin chooses what prompt text leaves the machines: off, redacted or full."
---

## What happened

Capture stays off until an Admin chooses what prompt text leaves the machines: off, redacted or full. There is no silent default.

## What to do

An Admin runs `casebox init` and chooses a prompt mode.

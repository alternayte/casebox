---
title: "CBX091: git user.email is not set"
description: "Capture counts distinct people by a pseudonymous token made from your git email; without it, capture refuses."
---

This page says what CBX091 means and how you fix it.

## What happened

Capture counts distinct people by a pseudonymous token made from your git email; without it, capture refuses.

## What to do

Set it: `git config --global user.email you@example.com`.
